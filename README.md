# OUT Messenger — client source

OUT is a private messenger for iPhone: no phone number, no chat history
on the device, end-to-end encryption, messages that vanish after reading.

The OUT iOS client is licensed under the GNU Affero General Public License v3.0
(AGPL-3.0-only) and uses LibSignalClient (AGPL-3.0).

## Getting the source code

The complete client source for each App Store release is available on request,
free of charge, to anyone who has the app.

Email info@outmessenger.com with the version you have
(for example "OUT 1.1.0, build 95") and we will send it.

More: https://outmessenger.com/source
