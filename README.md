## Source for version 1.0.0, build 4

Download **[OUT-1.0.0-build4-source.zip](https://github.com/markas11/OUT-source/releases/download/ios-1.0.0-build4/OUT-1.0.0-build4-source.zip)**
from the [versioned release](https://github.com/markas11/OUT-source/releases/tag/ios-1.0.0-build4).
It includes the OUT client, tests, build instructions, license notices, exact
LibSignal 0.99.4 source and 583 vendored native dependency packages. It is
available without an account or request. The release checksum is in SHA256SUMS.

Extract the ZIP and start with its README.md, client/BUILD.md and
dependencies/NATIVE-BUILD.md. The native iPhone library was successfully built
from these sources without downloading dependencies during that build.
No byte-identical compiler output or Apple approval is claimed.

This release is being prepared for TestFlight. Physical two-iPhone and real
StoreKit acceptance remain outstanding before public App Store launch.
The released app links to this versioned source page in Software notices.
Earlier test builds are not represented as byte-for-byte matches to build 4.
